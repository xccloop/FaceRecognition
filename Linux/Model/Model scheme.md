本方案将人脸识别拆分为三个步骤：人脸检测、人脸对齐、特征提取，全部通过 ncnn 推理框架在移动端或边缘设备上运行。
硬件平台：树莓派4b2g

第一步：人脸检测（使用 SCRFD）

作用：在输入图像中检测出人脸的位置，并输出人脸边界框和5个关键点。
输出内容：

bbox：人脸矩形框的四个坐标。

5个关键点：左眼、右眼、鼻子、左嘴角、右嘴角的坐标。
模型特点：SCRFD 采用多尺度检测架构，通过特征金字塔网络适应不同大小的人脸。模型导出为 .param 和 .bin 两个文件，分别存储网络结构和参数。ncnn 框架加载模型后，根据预设锚点生成候选框，再通过非极大值抑制得到最终检测结果。

第二步：人脸对齐（使用 OpenCV 仿射变换）

作用：将任意角度的人脸图像校正为正脸姿态，消除姿态差异。
实现方法：利用 SCRFD 输出的5个关键点，计算仿射变换矩阵，然后使用 OpenCV 的 warpAffine 函数进行仿射变换，最终得到一张 112x112 像素的标准正面人脸图像（即“对齐后的人脸”）。这一步是后续特征提取的关键预处理。

第三步：特征提取（使用 MobileFaceNet）

作用：从对齐后的112x112人脸图像中提取一个固定长度的特征向量，作为该人脸的“数字指纹”。
输入：112x112 的标准人脸图像。
输出：512 维的特征向量，例如 [0.123, -0.551, ..., 0.987]。
模型特点：MobileFaceNet 是为移动端优化的轻量级卷积神经网络，基于 MobileNetV2 改进，引入了全局深度卷积和线性瓶颈块，在保证精度的前提下显著降低计算量，适合在手机等资源受限设备上运行。

框架集成（ncnn）

ncnn 是一个专为移动端设计的高性能神经网络推理框架，零依赖，支持 CPU 和 GPU（Vulkan）加速，可运行于 Android、iOS、Linux 等平台。
运行流程：

ncnn 加载 SCRFD 的 .param 和 .bin 文件，在设备上执行人脸检测，得到 bbox 和 5 个关键点。

程序调用 OpenCV 的仿射变换函数，将原始图像中的人脸区域校正为 112x112 的标准正脸图像。

ncnn 加载 MobileFaceNet 的模型文件，将对齐后的人脸图像输入模型，前向推理得到 512 维特征向量。

该特征向量可用于后续的人脸比对（如计算余弦距离或欧氏距离）或存入数据库。
