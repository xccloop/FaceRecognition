# 树莓派端构建与运行指南

> 四端协同人脸识别项目 — 树莓派识别与控制端

## 1. 系统要求

| 项目 | 最低要求 | 推荐 |
|------|---------|------|
| 树莓派型号 | Pi 3B+ (1GB) | Pi 4/5 (4GB+) |
| 系统版本 | Raspberry Pi OS Bullseye (32-bit) | Bookworm (64-bit) |
| 摄像头 | USB UVC 摄像头 | 官方 Camera Module 3 / USB 720p+ |
| 存储 | 8GB SD 卡 | 32GB+（推荐 A2 等级） |
| 网络 | WiFi / 以太网 | 有线以太网（更稳定） |

## 3. 快速开始（首次部署）

### 3.1 烧录系统

使用 Raspberry Pi Imager 烧录 **Raspberry Pi OS Lite (64-bit)**：
- 建议关闭桌面环境节省资源
- 启用 SSH、设置 WiFi（Imager 高级选项中配置）

### 3.2 连接树莓派

```bash
# SSH 连接（树莓派插电后等待 1-2 分钟）
ssh pi@<树莓派IP>

# 更新系统
sudo apt update && sudo apt upgrade -y
```

### 3.3 传输项目文件

从 Windows 传输整个 `FaceRecognition` 目录到树莓派：

```bash
# 方案 A: SCP（从 Windows PowerShell / Git Bash）
scp -r D:\FaceRecognition\Linux\ pi@<树莓派IP>:~/FaceRecognition/

# 方案 B: U 盘 / SD 卡
# 将 FaceRecognition/ 目录复制到 U 盘，插入树莓派后：
cp -r /media/pi/USB/FaceRecognition ~/
```

**注意**：只需传输 `Linux/` 目录，Windows 端代码不需要在 Pi 上。

### 3.4 运行安装脚本

```bash
cd ~/FaceRecognition/"Raspberry Pi"
chmod +x scripts/install.sh
sudo ./scripts/install.sh
```

安装脚本会自动：
1. 安装系统依赖（apt）
2. 创建 Python 虚拟环境
3. 安装 Python 依赖（pip）
4. 检查 ONNX 模型文件
5. 安装 systemd 开机自启服务

### 3.5 配置参数

编辑 `config.json`，根据实际硬件修改：

```bash
nano config.json
```

关键配置项：

```jsonc
{
    "camera": {
        "device": 0,           // USB 摄像头通常为 0
        "width": 640,          // 分辨率（越高越慢）
        "height": 480,
        "fps": 15,             // 帧率（树莓派 3 建议 10）
        "backend": "opencv"    // Pi 5/Bookworm 可改为 "picamera2"
    },
    "recognition": {
        "model_dir": "../Model/models/onnx_models/buffalo_sc",
        "det_threshold": 0.5,   // 检测阈值
        "rec_threshold": 0.4,   // 识别阈值
        "max_side": 320         // 检测输入缩放（越小越快）
    },
    "uart": {
        "device": "/dev/ttyAMA0",  // Pi 3/4/5 主串口
        "baudrate": 9600,
        "commands": {
            "open": "OPEN\n",
            "close": "CLOSE\n",
            "reject": "REJECT\n"
        }
    },
    "mjpeg": {
        "port": 8080,          // MJPEG 流端口
        "quality": 50          // JPEG 质量（1-100，越低越省带宽）
    }
}
```

### 3.6 启动服务

```bash
# systemd 启动（开机自启）
sudo systemctl start face-recog
sudo systemctl status face-recog

# 或手动启动（前台调试）
./scripts/start.sh --debug

# 查看实时日志
tail -f /var/log/face-recog.log
```

### 3.7 验证

```bash
# 视频流是否正常
# 浏览器打开: http://<树莓派IP>:8080/video

# 串口是否正常（需连接 STM32）
ls /dev/ttyAMA0        # 应存在
sudo systemctl status face-recog | grep UART
```

## 4. 串口配置（与 STM32 通信）

### 4.1 启用硬件串口

树莓派默认将主串口分配给蓝牙，需要切换：

```bash
sudo raspi-config
# → Interface Options → Serial Port
# → "Would you like a login shell to be accessible over serial?" → No
# → "Would you like the serial port hardware to be enabled?" → Yes
# → Finish → 重启

# 或直接编辑 /boot/config.txt（Pi 5 改 /boot/firmware/config.txt）
echo "enable_uart=1" | sudo tee -a /boot/config.txt
echo "dtoverlay=disable-bt" | sudo tee -a /boot/config.txt
sudo systemctl disable bluetooth
sudo reboot
```

重启后验证：
```bash
ls -l /dev/serial0    # 应指向 /dev/ttyAMA0
sudo stty -F /dev/ttyAMA0 9600  # 测试串口
```

### 4.2 接线

| 树莓派 GPIO | STM32 |
|------------|-------|
| GPIO14 (TXD, Pin 8) | RX |
| GPIO15 (RXD, Pin 10) | TX |
| GND (Pin 6) | GND |

## 5. 性能优化

### 5.1 树莓派 3B+ 优化

```jsonc
{
    "camera": {
        "fps": 8,               // 降低帧率
        "width": 480,
        "height": 360
    },
    "recognition": {
        "max_side": 240,        // 更小的检测输入
        "det_threshold": 0.6    // 提高阈值减少误检
    },
    "runtime": {
        "skip_frames": 5,       // 更多跳帧
        "confirm_frames": 2
    },
    "mjpeg": {
        "quality": 30           // 降低 JPEG 质量
    }
}
```

### 5.2 通用优化

```bash
# 1. 固定 CPU 频率（避免降频）
sudo cpufreq-set -g performance

# 2. 增大 GPU 内存（如果有 GUI）
sudo raspi-config → Performance → GPU Memory → 128MB

# 3. 关闭不必要的服务
sudo systemctl disable bluetooth avahi-daemon triggerhappy
```

### 5.3 使用 CSI 摄像头

Pi Camera Module 2/3 延迟更低。将 `backend` 改为 `picamera2`：

```jsonc
{
    "camera": {
        "backend": "picamera2",
        "device": 0
    }
}
```

需先启用 CSI 接口：
```bash
sudo raspi-config → Interface Options → Camera → Enable → 重启
```

## 6. 用 Windows 管理端联调

### 6.1 同步人员特征

在 Windows 管理端 → 人员管理 → 注册人脸 → 点击"同步到 Pi"按钮。

内部流程：
1. Windows 通过 SSH/SCP 将 `.bin` 特征文件传到 `features/` 目录
2. 树莓派的 `FeatureDB` 热加载检测到文件变化，自动更新内存库
3. 无需重启服务

### 6.2 实时画面

Windows 端"实时画面"页面直接访问：
```
http://<树莓派IP>:8080/video
```

## 7. 故障排查

| 问题 | 解决方法 |
|------|---------|
| `[Camera] 无法打开摄像头` | `ls /dev/video*` 检查设备；`sudo chmod 666 /dev/video0` |
| `[FeatureDB] 特征库为空` | 通过 Windows 端同步人员特征 |
| `ModuleNotFoundError: onnxruntime` | `source venv/bin/activate && pip install onnxruntime` |
| `[UART] 无法打开 /dev/ttyAMA0` | 检查第 4 节串口配置 |
| 视频流很卡/断连 | 降低分辨率/JPG质量，使用有线网络 |
| 识别太慢（>500ms/帧） | 降低 max_side 和 fps，增加 skip_frames |

## 8. 完整管线流程

```
摄像头 → FrameQueue → 推理线程 → ResultQueue → UART → STM32 → 继电器 → 门锁
  ↓                        ↓                       ↓
MJPEG流 ←── 取帧      FeatureDB 匹配        识别结果日志
(Windows 实时画面)     (匹配注册人员)        (/var/log/face-recog.log)
```
