# Raspberry Pi 端完整实现计划

> **For Hermes:** 按任务顺序逐一实现，使用 `src/` 子目录组织代码，先写代码后写文档。

**Goal:** 构建树莓派端人脸识别完整运行时系统，包含摄像头采集→推理识别→串口通信→视频流四层管线。

**Architecture:** Python 多线程架构。采集线程 → FrameQueue → 推理线程 → ResultQueue → 串口发送线程。同时运行 Flask MJPEG 视频流 + HTTP API 线程。

**Tech Stack:** Python 3.9+, onnxruntime, OpenCV, pyserial, Flask

**目录结构:**
```
Raspberry Pi/
├── config.json              # 运行配置
├── main.py                  # 主入口（启动所有线程）
├── requirements.txt         # Python 依赖
├── src/
│   ├── __init__.py
│   ├── config.py            # 加载/解析 config.json
│   ├── camera.py            # 摄像头采集 + FrameQueue
│   ├── inference.py         # 人脸检测+对齐+特征提取+匹配
│   ├── feature_db.py        # 特征库（二进制格式读写）
│   ├── uart.py              # 串口帧编解码+收发线程
│   ├── recognition.py       # 识别管线（复用 Model/ 下 ONNX 模型）
│   └── mjpeg.py             # MJPEG 视频流 Flask 服务
├── scripts/
│   ├── install.sh           # 一键安装脚本
│   ├── start.sh             # 启动脚本
│   └── face_recog.service   # systemd 自启服务
├── features/                # 人脸特征目录（空目录，运行时生成 .bin）
└── models -> ../Model/models # 符号链接到模型目录
```

## 任务 5: 特征库 FeatureDB

**目标:** 二进制格式读写人脸特征（与 C++ 兼容），内存缓存全量特征

**文件:**
- `Raspberry Pi/src/feature_db.py`

**实现要点:**
- 加载：从 `features/*.bin` 读取所有人员特征到内存 dict（兼容 verify.py 格式）
- 匹配：余弦相似度（归一化特征做点积），返回最高分 > 阈值的结果

- 支持 inotify 热加载（可选）

## 任务 6: 推理线程

**目标:** 从 FrameQueue 取帧 → 检测 → 对齐 → 提取 → 匹配 → 推结果到 ResultQueue

**文件:**
- `Raspberry Pi/src/inference.py`

**实现要点:**
- 跳帧策略：每 N 帧推理一次，其余复用跟踪结果
- 多目标跟踪：基于 IOU 的人脸跟踪 + 特征缓存
- 防抖动过滤：N 帧内连续识别到同一人才确认
- 超时警告：推理超 200ms 打印警告
- 结果结构：`{track_id, name, confidence, bbox, timestamp}`

## 任务 7: UART 串口通信

**目标:** 与 STM32 通过串口通信，发送识别结果 + 接收命令

**文件:**
- `Raspberry Pi/src/uart.py`

**实现要点:**
- 初始化：打开 `/dev/serial0`，115200-8-N-1
- 帧编码：0xAA → CMD(1B) → DIR(1B) → LEN(2B) → DATA → XOR → 0x55
- 数据区转义：0xAA→0xBB+0x55, 0x55→0xBB+0xAA, 0xBB→0xBB+0x44
- 发送线程：从 ResultQueue 取结果，编码后发送
- 接收线程：读串口字节，解码后入命令队列
- 心跳：每 5 秒发送心跳帧
