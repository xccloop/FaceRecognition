## 建议

1. 阈值选择应根据实际部署场景的光照、角度、遮挡条件调整
2. 门禁场景建议 FAR < 0.1%，可接受较高 FRR（人工处理拒绝案例）
3. 办公考勤场景可放宽 FAR < 1%，优先降低 FRR
4. 建议在实际部署环境中采集 100+ 人各 5+ 张照片后重新跑 benchmark
